Обзор проекта

Этот проект анализирует набор данных US Flights за 2008 год, содержащий более 7 миллионов летных записей. Целью было изучить производительность авиакомпаний, задержки, отмены рейсов, популярность маршрутов и временные закономерности с помощью библиотек анализа данных на Python.

Проект демонстрирует практические навыки аналитики данных, включая очистку данных, агрегирование, статистический анализ, генерацию бизнес-аналитики и визуализацию данных.

Результаты
Анализ выявил ключевые операционные тенденции в авиационной отрасли США, включая периоды пикового трафика, крупные отмены пилотов, различия в надёжности авиакомпаний и характеристики маршрутов.
